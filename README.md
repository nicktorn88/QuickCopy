# QuickCopy

QuickCopy is a lightweight Windows desktop app for creating reusable notes that can be copied to your clipboard with one click.

It is designed for text you use repeatedly, such as messages, instructions, addresses, templates, commands, or anything else you are tired of typing over and over.

![QuickCopy screenshot](Screenshot%202026-08-12%20115302.png)

## Features

* Create and save reusable notes
* Copy any note to the clipboard with one click
* Open notes as independent floating windows
* Optional **Stay on Top** for floating notes
* Remembers floating note position and size
* Notes persist between restarts
* Runs quietly in the Windows system tray
* Optional **Start with Windows**
* Single-instance protection
* Backup and restore notes
* Notes are preserved through updates and reinstalls

## Download

Open the **Releases** section of this repository and download the latest:

`QuickCopySetup-1.0.0.exe`

QuickCopy currently supports **64-bit Windows 10 and Windows 11**.

## Installation

1. Download `QuickCopySetup-1.0.0.exe` from the latest release.
2. Run the installer.
3. Launch QuickCopy from the Start Menu.
4. Create a note and click **Copy** whenever you need its text.

## Windows Security Notice

QuickCopy v1.0.0 is currently **unsigned**.

Because it is a new application without an established Windows reputation, Microsoft Defender SmartScreen or antivirus software may display a warning when downloading or installing it.

Code signing is planned for a future release.

## Where QuickCopy Stores Your Notes

QuickCopy stores your notes locally in:

`%AppData%\QuickCopy\notes.json`

Uninstalling QuickCopy does not automatically delete your saved notes, allowing them to remain available if you reinstall the application later.
